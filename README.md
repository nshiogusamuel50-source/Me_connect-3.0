# ME Connect 2.0 — working prototype

Features: account registration/login, member profiles, create posts, likes/unlikes, comments, follow/unfollow, explore people and share posts.

**Important prototype limitation:** account and post data are stored in the current browser's local storage. They are not shared between different phones or browsers. This is not production authentication; passwords are stored locally. Do not reuse a real password or enter sensitive information. A secure backend/database and server-side authentication are required before public launch.

Meta Earth / ME Network, ME ID / digital identity, notifications and messaging are marked Coming Soon.
